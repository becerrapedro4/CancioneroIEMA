🎦 Holyrics
Conectá la PC que presenta con Holyrics y el stage de una sala muestra lo que Holyrics tiene en pantalla (actual y siguiente, o solo actual, según el preset). Los datos salen de Holyrics → Configuración → API Server: ahí están la IP, el puerto y el token (opción «administrar permisos»).
—
—
—
Cómo llega: el stage de esa sala muestra lo que Holyrics tiene en pantalla, y el que le pregunta a Holyrics es el primero de estos dos que esté disponible:
1. Este admin, mientras esta pestaña esté abierta en una PC que alcance a Holyrics (una página en http:// o abierta desde el archivo). No hace falta nada más: mirá arriba si dice que está publicando.
2. El puente, para que siga andando con el admin cerrado — corre en la misma PC del programa:
node puente-holyrics.js --sala NOMBRE_DE_LA_SALA
Una página https:// (la publicada) no puede llegar al API http:// de la PC: si abrís el admin desde ahí, el que publica es el puente.
El token queda en la base (se lee sin login): es el del API Server local, no lo uses para otra cosa.

🧹 Canciones repetidas
—
Grupos de canciones que son la misma: el mismo título escrito distinto (tildes, mayúsculas, signos o espacios), la misma letra con otro título o la letra casi igual (coincide en un 90% o más). Al resolver un grupo queda la que elijas y se borran las demás en mejoras; después publicalo con 🚀 Publicar en main. No se cambia nada hasta que elijas, y la canción que queda se guarda tal cual está.
